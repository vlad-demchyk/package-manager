Simulator

Build a command

Pick a command, a mode and options: next to them (below on a phone) you get the command line, what it reads and writes, when it asks for confirmation and a sample output. Options come from the CLI code; the output was captured live by read-only runs on a synthetic demo repository. The state lives in the page address, so a link can be shared.

The simulator needs JavaScript.

Keyboard

Keys Action
Tab / Shift+Tab command groups, list, mode, arguments, options
← → previous or next group (on the tabs and in the command list)
↑ ↓, j k, Home End pick a command in the list
Space / Enter turn an option on or off
R reset options and mode
/ site search

How to read it

  • captured live: output of a real run. When exactly that command was not captured, the closest run is shown with its exact command line.
  • illustration from code: for commands that change files, run npm or need a site; the text is built from the messages in the code, not from a live run.
  • no effect here: the command accepts a shared option but turns that part of the analysis off itself (for example, list never queries advisories).
  • The Group mode selects projects by id with a glob mask; there is no separate flag for version groups.
