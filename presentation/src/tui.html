Interface

TUI

packman without a command in an interactive terminal (stdin and stdout are a TTY, CI is not set) opens the TUI on the alternate screen. Explicitly: packman tui [path] with the same -p, -x, --depth, --offline, --no-security, --no-usage. The description below follows the code of src/tui/App.tsx.

What is on the screen

  • Header: "packman report" and the workspace root; on the right the counts critical/error/warning/info.
  • Tabs numbered 1-7; Fixes shows the number of selected fixes in brackets; next to them the filter "showing ... and worse".
  • Tab content: a list with a › cursor and, for the selected row, a box with details.
  • Key hints at the bottom; while loading, the progress is shown as packman… [3/7] webparts/team-calendar.

Tabs

# Tab What it shows Space
1 Overview Version groups (up to 6) with the baseline and Node; workspace findings with the details and fixes of the selected one. select every fix of the finding
2 Projects Counts, id, stacks, Node. Enter opens a project: Node (installed and recommended), where the code runs, network calls, findings with evidence (up to 8 lines). in a project: select the fix of the finding
3 Versions Only packages with different versions; the box shows which projects use which version. align the package (align/package)
4 Outdated Asks the npm registry the first time the tab opens: current, newest in major, latest, deprecated. update within the major (outdated/in-major)
5 Node Installed Node versions: manager, support phase, CVEs, how many projects use each, latest of the line. -
6 Store The union plan: key, mode, size, Node, how many are linked already; members, warnings and a ready store link command. Read-only. -
7 Fixes Files the selected fixes change, and the diff of the selected file. -

Keys

Key Action
↑ ↓ / k j move the cursor; PgUp PgDn by the list height, Home End to the edge
Tab, → / Shift+Tab, ← next / previous tab (not in project details)
1...7 go to the tab
Enter open a project (Projects tab)
Esc / Backspace close project details
Space select or deselect the fix of the row
u select or deselect every profile fix (profile/*), like profile apply
s cycle the minimum severity: info, warning, error, critical
a in the Fixes tab: apply; then y confirms (also s for Italian and т for Ukrainian), any other key cancels
r reread the configuration, manifests, lockfiles and installed versions; the selection is reset
q / Ctrl+C quit

What applying does

  • Writes the selected changes with a backup in .packman/backups/<time>/ and rereads the report.
  • Does not relock and does not write to the journal. After version edits run packman relock -p <project>.
  • Fixes of any risk can be selected by hand: the TUI does not filter by --risk; the risk is shown in the box as [safe], [review], [breaking].

The TUI does not install packages, link the store or run npm: use the CLI for that (install, store link, relock).
