    Commands

    Every command and option comes from the commander tree in src/cli/**; the explanations are checked against the code. The original description from the code is shown in grey under each option.

    Shared options of most commands: [path] (root, default .), -p, --project, -x, --exclude, --depth, --lang, --offline, --no-security, --no-usage. The no effect here tag means the command turns that part of the analysis off itself.

    packman without a command opens tui in an interactive terminal (not CI) and runs check otherwise. sp is an alias of sharepoint.
